# MG-21 给人看的字有英文，安装脚本装的新版不叫人删

两件事（2026-11-17）：迁移程序给人看的字原来只有写死的中文，补上英文；数据根外面的 `~/.local/bin/miyu` 认新版的办法换成稳的。

## 为什么

- 程序的输出（帮助、报错、跑完印的两行）、给人看的报告（正文、每节标题、各类那一句）、报告的文件名全是写死的中文，界面语言是
  英文的人看不懂。报错原来反过来只有英文。
- 零碎那一节只认 `~/.local/bin/miyu` 里有没有 `miyu-remake` 字样。新版安装脚本（核心 `packaging/install.sh`）在那里放的是链接，
  指到 `~/.local/lib/miyu/miyu`（旁边写 `install.toml`，`channel = "script"`），程序本体里没有这几个字，就被当成旧版、报告叫人删。

## 改了什么

### 英文

1. 字集中在 `src/words.rs` 和 `src/words/` 下的小字表里：`cli`（帮助、跑完的两行、报错）、`report`（报告的框架、状态、两个文件名、
   留给人的目录名）、`sessions`（会话、QQ 消息记录）、`memories`、`personas`（压缩包、人格）、`files`（文件、知识库）、`packages`
   （技能、脚本、包、登录态、表情包）、`setup`（配置、赞助）、`leftovers`。一张表一个结构体，`ZH`、`EN` 各一份，用的地方
   `Language::pick` 挑一张；带数的是函数指针。并句、列举、字节数照语言用各自的标点（`Language::sentences`、`list`、`human_size`）。
2. 语言：`Language::system()` 照 `LC_ALL`、`LC_MESSAGES`、`LANG` 头一个不空的（同核心握手报的 `locale`，用 `miyu_client::open::locale`），
   `Language::from_core` 照握手回的 `language`（钉住的 miyu-client `65b0c218` 有 `open::Core::language()`，`Live::language()` 转出来）。
   `zh` 开头的是中文，别的（`ja` 也是）英文。`main.rs` 连上以前用系统语言，连上以后用核心的；`Plan` 多一个 `language`。
3. 各类迁的时候照 `Plan.language` 写那一句（`migrate(…, language)`），报告 `human(language)`、`write(dir, language)`。英文的文件名
   `report.md`、`for-agent.json`，目录 `root/documents/Old Miyu migration/<时刻>/`；中文的照旧。
4. 报错：`RunError`、`LayoutError`、`ArchiveError` 有 `say(language)`，`Display` 是英文那一句。英文照成熟 Linux 程序：
   `miyu migrate: <小写开头、不带句号>`；中文照 GNU 中文翻译的书面语。
5. 给人看的报告里，几份的来源照语言重新列（英文用逗号）；给 agent 的那份里照旧用「、」并。

### 认新版

`leftovers.rs` 的 `is_new_miyu`：先 `fs::canonicalize` 解开链接，落在 `~/.local/lib/miyu/` 下、那里有 `install.toml` 的算新版；
照旧是文件、里面写着 `miyu-remake` 的（早先的包装脚本）也算。不跑那个程序问 `--version`。备注改成「这是新版的 miyu，不是旧版的，别删」。

## 不做什么

- 不做日文：包里没有日文字表，`ja` 照英文。
- 给 agent 的那份的结构不变（键、状态词、`skipped.why`、`pending` 都不变）；`format`、`note` 这两格的字照这一次的语言写。
- 写进新版的数据不跟着语言变：会话里的提示、旧图片的占位、「旧版被挤出的对话」、表情包的来源、`root/workspace/旧版/`、
  `root/documents/旧版产物/`、改名用的「(旧版 N)」——换了语言重跑要认得出以前迁过的，名字不能变。知识库新建时的名字、说明照语言写
  （库编号 `legacy` 不变，建过的不再建）。
- 连核心的库（miyu-client）自己的话照原样转出来（例如连不上时它说的中文），不在这个包里改。

## 怎么验

- 改前红：`report::tests::the_report_reads_in_english_when_asked`、`run::tests::an_english_run_writes_english_reports`（英文跑一次，
  文件名、目录名是英文，报告里没有一个汉字）、`leftovers::tests::a_link_into_the_installed_lib_is_the_new_version`（链到
  `<家>/.local/lib/miyu/miyu` 的认成新版，链到别处的照旧当旧版；Windows 建不了链接，只在 unix 上跑）。
- 另有 `leftovers_read_in_english_when_asked`、`errors_are_said_in_either_language`、`words::tests`。
- 本机 `cargo fmt --all --check`、`cargo clippy --workspace --all-targets --locked -- -D warnings`（加 `--target x86_64-pc-windows-gnu`）、
  `cargo test --workspace --locked`；分支的三台 CI。
- 实测：造一份最小的旧根，沙箱数据根起 `/usr/bin/miyu core`，假的家目录里 `~/.local/bin/miyu` 链到 `~/.local/lib/miyu/miyu`；
  `LANG=en_US.UTF-8` 跑出 `Old Miyu migration/<时刻>/report.md`、`for-agent.json`，正文英文，链接报「This is the new miyu」；
  `LANG=zh_CN.UTF-8` 跑出的照旧是中文。
