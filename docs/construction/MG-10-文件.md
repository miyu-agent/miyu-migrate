# MG-10 图片、文档、产物、工作目录

照细则第九节。另带一个知识库的小修（core1 合 MG-9 时提的）。

## 做什么

1. 旧版给你存的文件拷进新数据根的同类目录（直接写文件，同技能、知识库）：
   - `home/<管>/pictures/`、`data/pictures/`（两处都有的合并）→ `root/pictures/`；
   - `home/<管>/documents/` → `root/documents/`；
   - `home/<管>/artifacts/<旧会话>/` → `root/documents/旧版产物/<会话名>/`：会话有名字的照名字（去掉路径分隔、控制字符，最长 80 个字），
     没名字的照导进去的存档的新编号（同 MG-3 的算法），对得上存档；会话库读不了的照旧编号；
   - `home/<管>/workspace/`、根目录 `workspace/` → `root/workspace/旧版/`；
   - `home/<管>/shares/` 不迁，报 `shares`。
2. 同名的：字节一样的算以前迁过，不一样的改成 `<名> (旧版 N).<后缀>` 并列进报告。拷完读回比 SHA-256，对不上的数出来。链接不跟、
   不拷，报 `link`。
3. 知识库：这一次拷了新文档的，报告加一句「第一次列出、搜这个库之前新版会先建索引，篇数多要等一会儿，不是卡住了」。

## 怎么验

- 单元：几类目录拷到哪（两处图片合并、产物照会话名和新编号、两处工作目录）、新版的不盖、改名、分享不迁、链接不拷、再跑一遍不拷；
  会话名当目录名的写法；没有文件的。知识库那一句：拷了新的说、没拷的不说。
- 演练（主人旧根的副本）：拷了 251 个文件；跳过 3 个链接（旧工作目录 `.cache/fontconfig` 里的缓存链接）；第二遍 251 个都是以前迁过的。
