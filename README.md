# miyu-migrate

把旧版 Miyu（0.7.x）的数据目录迁进新版 Miyu。新版的软件包：装上以后多一条 `miyu migrate`。

```
miyu pkg install miyu-migrate
mv ~/.miyu ~/.miyu-0.7        # 先停掉旧版，再把旧目录挪开
miyu migrate ~/.miyu-0.7
```

它先把旧目录整个打成压缩包、逐个文件核对，然后只从解出来的副本读，经新版核心的协议写进去，最后出两份报告：一份给人看，
一份给 agent 读（写明没迁的东西在压缩包里的哪个路径、旧格式是什么样，要的时候让 agent 接着迁）。旧目录不动。

迁移程序连新版核心的身份就是在终端里跑它的人（读数据根的 `run/token`），核心没在跑会照 `miyu core` 拉起。动手前会先查：旧版
停了没有（`daemon.lock`），状态目录那块盘够不够（要旧目录大小的两倍）。

现在迁的：

- **人格**：旧版的 Miyu 新建成名字叫 Miyu 的人格（提示词取旧版原文，`crates/miyu-migrate/legacy/`，你改过的角色扮演提示、
  示范对话盖在上面）；`data/prompts/` 里自己建的每一个新建一个；开发模式映射到出厂的软件工程师。新版里已经有同名人格的不建，
  直接用它。人格的子系统、插件开关新版没有对应，写进报告。
- **会话**：每个会话导成一个只读存档（能翻、能搜，不能接着聊），字、工具调用和结果、上传的附件都在；摘要行是派生的，
  不导。会话编号由旧编号算出来，重跑不会重复导。
  - QQ 里的会话导成那个群、那个私聊的存档（和新版的 QQ 会话一样不进会话列表，回合库记得是哪个群）：群里的一轮照每行开头的
    号拆成每个人说的话，私聊是对方说的。
  - 旧版压缩时搬走的轮（`evicted_context.db`）照时刻插回原来的会话；原来的会话不在了的，照人格归进一个「旧版被挤出的对话」。
  - 工具出的图、内嵌给模型看的图、溢出的长输出接在那一条工具结果后面；她问你的问题（`ask_user`）、你中途插的话、只留了展示转录
    的工具来回都在；子代理的会话作子会话，和它的主会话一起导。

- **QQ 消息记录**：旧版记下的群聊、私聊消息转成 im 收的写法（迁移目录里的 `qq-records.jsonl`），交 `miyu im records import`
  导进 im 的库；im 认得出已经有的（重跑、新 im 并行接过的那一段），不会多出来。im 没装的，报告里写装上以后跑哪一行。

- **记忆**：每个旧人格记下的知识点导进映射到的那个新人格（原来记下的时刻留着），说的是别人的记成那个人的，说的是你的记成你的；
  她自己的、超过 120 字的不导，报告里写在压缩包的哪一行。导完让新版整理一次，合掉和已经记下的重复。重跑不会重复导，删掉的也不会
  导回来。

- **配置和密钥**：供应商（地址、key、模型的窗口、温度、价格）、主对话和看图的模型、子代理的几个池、搜索的 key、关于你、你的 QQ 号，
  补进新版的设置；只补新版没有的，新版已经配过的不动。key 写进新版的密钥文件，报告里只写名字。新版没有对应的整段（上下文调参、
  显示、语音……）写进报告。

- **表情包**：你自己收的那几个库各做成一个表情包的内容包（图、描述、什么时候用、从哪收来的），装着表情包的直接装上；没装的包留在
  迁移目录里，报告写装上以后跑哪一行。

- **技能、脚本**：你自己写的技能拷进新版的技能目录（同名的不覆盖，改名并列进报告）；自己写的脚本新版格式不一样，原样留在压缩包里，
  报告逐个列出，官方源里已经有同名新包的提示装。旧版包管理器装的不拷，报告里写到官方源装哪个新包。

- **知识库**：你自己放的文档拷进新版的一个库「旧版知识库」（`root/kb/legacy/`），新版自己建索引；旧版内置的默认库不迁。

- **文件**：旧版给你存的图片、文档、工具产出的产物（照会话分好）、工作目录，拷进新版的图片、文档、工作区目录；新版里已经有同名
  不一样的不覆盖，改名并列进报告。以前给别人的分享不迁。

- **搜索脚本的登录态**：闲鱼的拷进新包 `miyu-scripts-goofish` 的状态目录（包装着的话）；知乎、小红书、B 站搜索新版还没有包，登录态
  留在压缩包里；B 站开播的新包装上以后重新登录。报告里只写站点和条数，不写 cookie。

- **赞助记录**：交 im 的赞助插件导进它的账本（原来的时刻、金额、汇率照旧），插件认得出已经有的，重跑不多；插件没装的报告写装上
  以后重跑。

新版核心一个字节都不认旧格式：旧用户都迁完以后，这个包下架、仓库归档。
